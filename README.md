#  Ferris Wheel

A simple animated Ferris Wheel built with **HTML and CSS** as part of the FreeCodeCamp Responsive Web Design course.

##  Project Overview

This project demonstrates how to create a Ferris Wheel using HTML elements and CSS styling. The wheel and cabins are animated using CSS `@keyframes`.

##  Technologies Used

* HTML5
* CSS3
* CSS Animations
* Positioning and Transforms

##  Features

* Circular Ferris Wheel design
* Six cabins
* Rotating wheel animation
* Moving cabin animations
* Cabin colors change during the animation
* Responsive sizing using `vw` and maximum dimensions

##  What I Practiced

Through this project, I practiced:

* Using `position: absolute`
* Creating circular shapes with `border-radius`
* Using `transform` and `rotate()`
* Creating animations with `@keyframes`
* Using `animation-duration`, `animation-iteration-count`, and `animation-timing-function`
* Positioning multiple elements around a circle

##  How to Run

1. Download or clone the repository.
2. Open `index.html` in a web browser.
3. The Ferris Wheel animation will start automatically.
